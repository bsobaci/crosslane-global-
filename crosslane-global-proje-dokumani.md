## 6. AGENT SİSTEMİ

### Genel Mimari
```
Telegram Bot (Sen komut yazarsın)
        ↓
    n8n Workflow
        ↓
  Gemini 2.0 Flash API (Ücretsiz)
        ↓
  SAM.gov API / Web fetch
        ↓
  WordPress REST API
        ↓
  Site güncellenir → Telegram'a bildirim
```

### Araç Yığını (Tamamı Ücretsiz)
| Araç | Amaç | Maliyet |
|------|------|---------|
| Telegram Bot | Komut arayüzü | Ücretsiz |
| n8n (self-hosted) | Otomasyon motoru | Ücretsiz |
| Gemini 2.0 Flash API | AI yazma & analiz | Ücretsiz (günlük 1500 istek) |
| SAM.gov API | İhale verileri | Ücretsiz |
| WordPress REST API | Site güncelleme | Ücretsiz |
| Railway.app | n8n hosting | Ücretsiz tier |
| Google Sheets | Basit veri depolama | Ücretsiz |

### Telegram Bot Kurulumu
1. Telegram'da `@BotFather`'a yaz
2. `/newbot` komutu gönder
3. Bot adı: `CrosslaneAgent`
4. Token'ı kaydet → n8n'e ekle

### Gemini API Kurulumu
1. console.cloud.google.com → yeni proje
2. "Generative Language API" aktif et
3. API anahtarı oluştur → n8n'e ekle
4. Model: `gemini-2.0-flash` (ücretsiz tier)

### SAM.gov API Kurulumu
1. sam.gov/profile → hesap oluştur
2. API key al (ücretsiz, kayıt yeterli)
3. Endpoint: `https://api.sam.gov/opportunities/v2/search`
4. Filtreler: NAICS kodu, tarih aralığı, bütçe

### WordPress REST API Kurulumu
1. WordPress → Kullanıcılar → Uygulama Şifreleri → Yeni şifre oluştur
2. Base URL: `https://crosslaneglobal.com/wp-json/wp/v2/`
3. Endpoints: `/posts`, `/pages`, `/media`

### n8n Workflow'ları

#### Workflow 1: Günlük SAM.gov Tarama
```
Trigger: Her gün 08:00
  → SAM.gov API'den son 24 saatin ihalelerini çek
  → NAICS filtresi uygula (IT, Gayrimenkul, Danışmanlık)
  → Gemini ile Türkçe + İngilizce özet yaz
  → WordPress'e yeni "opportunity" post olarak ekle
  → Telegram'a günlük özet gönder
```

#### Workflow 2: Telegram Komut İşleme
```
Trigger: Telegram'dan mesaj geldiğinde
  → Gemini ile niyet analizi yap (ne yapılmak isteniyor?)
  → Uygun aksiyonu tetikle:
    * "sil" → WordPress post sil
    * "ekle" → WordPress post ekle
    * "yaz" → Gemini ile içerik üret, Telegram'a gönder, onay bekle
    * "yayınla" → Onaylanan içeriği WordPress'e yayınla
    * "listele" → Mevcut içerikleri listele
  → Sonucu Telegram'a bildir
```

#### Workflow 3: Aylık İstatistik Güncelleme
```
Trigger: Ayın 1'i
  → SelectUSA sayfasını çek (trade.gov/selectusa)
  → Gemini ile yeni rakamları çıkar
  → Ana sayfadaki istatistik kartlarını güncelle
  → Telegram'a bildirim gönder
```

#### Workflow 4: Haftalık Insights Taslağı
```
Trigger: Her Pazartesi
  → SAM.gov'dan trend analizi yap
  → Gemini ile TR + EN insights yazısı taslağı oluştur
  → Telegram'a gönder ("Onaylıyor musun?")
  → "Evet" → WordPress'e taslak olarak kaydet
  → "Hayır" → iptal
```
